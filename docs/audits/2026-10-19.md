## Prioritized findings

Severity: P1 = major supported functionality broken; P2 = incorrect results under narrower supported inputs; P3 = boundary defect or dependency maintenance. Confidence and scope are stated separately.

### A1 — P1, confirmed: Rust STAC searches discard the final endpoint segment

[`StacProvider::search_pages`](../../crates/satellites-images/src/lib.rs) at line 809 calls `.join("search")` on endpoints without a trailing slash. URL resolution replaces the last path segment: Planetary Computer requests `/api/stac/search` instead of `/api/stac/v1/search`; INPE requests `/bdc/stac/search` instead of `/bdc/stac/v1/search`; NASA CMR's ASF base requests `/stac/search` instead of `/stac/ASF/search`. Built-in Copernicus and USGS bases have the same construction problem. Earth Search has a trailing slash and is unaffected by this particular defect.

The current Rust SDK was exercised against a local HTTP server; actual received paths confirm the three nested-base failures and a passing trailing-slash control. This is not a claim of fresh live Rust-provider validation. [Captured reproduction](../../tools/audit/results/2026-10-19-rust-path-repro.log).

**Remediation:** normalize endpoints as directory URLs before joining; verify nested custom endpoints and every built-in constructor with request-path assertions.

### A2 — P2, confirmed: Explorer can report complete results after stopping before an unsearched box

[`scanNextBatch`](../../apps/explorer/src/main.ts) at line 1318 ends a session once aggregate pages reach 50. At line 1337, a true `summary.complete` clears the warning. SDK availability tracks the last yielded page's `hasNext`, which can be false at the end of one antimeridian box even while another box remains unsearched.

The exact current explorer function, with UI callbacks stubbed and real SDK generators, stopped at 50 pages with `complete: true`, empty status, and no truncated providers. One additional generator request returned `omitted-west-scene`. This reproduction exercises the orchestration function outside a browser; the separate browser suite passes its existing fixtures. [Captured reproduction](../../tools/audit/results/2026-10-19-cap-repro.log).

**Remediation:** track exhaustion of all provider/box iterators explicitly; a safety-limit stop must retain an incomplete state whenever work remains.

### A3 — P2, confirmed in TypeScript/Python: Mixed MultiPolygon queries can omit a requested region

[`polygonBoxes`](../../packages/typescript/src/index.ts) at line 189 and Python's [`polygon_boxes`](../../packages/python/src/satellites_images/catalog.py) at line 231 flatten all rings before dividing longitudes around the antimeridian. A MultiPolygon combining a 179°/−179° rectangle with a −1°/+1° rectangle produces `[[-180,0,-1,12],[1,0,180,12]]`, excluding the requested interior point `[0,0.5]` near Greenwich. Rust's corresponding algorithm at [`lib.rs:254`](../../crates/satellites-images/src/lib.rs) matches on inspection; this geometry reproduction was not executed in Rust.

**Remediation:** calculate conservative coverage per polygon, then combine boxes without losing non-crossing components. [TypeScript evidence](../../tools/audit/results/2026-10-19-spatial-ts-repro.log), [Python evidence](../../tools/audit/results/2026-10-19-spatial-python-repro.log).

### A4 — P3, confirmed in TypeScript/Python: Day filters omit fractional timestamps in the final second

STAC intervals end at `T23:59:59Z`: [`index.ts:289`](../../packages/typescript/src/index.ts), [`catalog.py:483`](../../packages/python/src/satellites_images/catalog.py), and [`lib.rs:797`](../../crates/satellites-images/src/lib.rs). An observation at `23:59:59.500Z` falls outside that interval. Against a mock service honoring the requested interval, TypeScript and Python return zero items and report complete results. Rust's matching interval construction was inspected but not executed for this reproduction.

**Remediation:** define full-day coverage that includes fractional timestamps, with appropriate next-day boundary handling and consistent behavior across SDKs. Evidence is in the spatial/time logs linked above.

### A5 — P3, scanner-confirmed: Locked Rustls has four advisories

[`Cargo.lock:740`](../../crates/satellites-images/Cargo.lock) selects `rustls 0.23.45`. Fresh `cargo audit` exits 1 and reports RUSTSEC-2026-0346, RUSTSEC-2026-0347, RUSTSEC-2026-0348 and RUSTSEC-2026-0349; its patched range is `>=0.23.46`. [Scanner JSON](../../tools/audit/results/2026-10-19-cargo-audit.json).

This is not evidence of four exploitable paths in the application. The fresh [feature tree](../../tools/audit/results/2026-10-19-rustls-features.log) selects `ring`, `std` and `tls12`, without `brotli`. Targeted source review found ordinary Reqwest clients and no direct custom Rustls session store or ECH configuration. The [16 October audit](2026-10-16-codebase.md) contains the prior advisory applicability analysis and primary advisory links; that analysis should be reassessed if consumer feature unification changes the graph.

**Remediation:** regenerate the lockfile with a patched compatible Rustls selection and repeat Rust, minimum-runtime and installed-package checks. No dependency upgrade was applied in this audit.

## Engineering assessment and limits

- **Architecture and maintainability:** shared registry generation and cross-language fixtures are useful foundations. Duplicated geometry/time behavior and the large explorer orchestration module need explicit cross-language boundary coverage; A1–A4 show current blind spots.
- **Testing and packaging:** broad deterministic coverage and isolated installed-consumer checks pass. Their success does not establish live endpoint correctness or completeness for untested input combinations.
- **Security and dependencies:** npm reports no known dependency vulnerabilities; Rust requires lock maintenance. Targeted review observed bounded metadata handling, cancellation, disabled metadata redirects and omitted browser preview credentials. This was not a penetration test or full secret-history audit.
- **Operations and documentation:** inspected manifests, CI configuration, repository instructions, earlier audit evidence and current search/preview boundaries. CI declares runtime matrices and offline browser checks; hosted CI was not triggered. Existing workflow edits were preserved.
- **Performance and providers:** no new benchmarks or live-provider probes were run in this turn. [16 October measurements and source checks](2026-10-16.md) remain dated evidence, not fresh results. No imagery was downloaded or uploaded by this audit.

Minimum-runtime checks, all CI platforms, fresh provider CORS/coverage, raster correctness, hosted deployment, authenticated services and publishing were not validated in this turn. The working tree remains uncommitted; synchronizing committed `main` does not publish or merge that local work.
